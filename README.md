# 🌾 田园小农场 - 休闲种植小游戏

一款可爱的休闲种植小游戏，体验田园生活的乐趣！

## 🎮 游戏特色

- 🌱 **种植系统**：6种作物，从白菜到西瓜，体验不同生长周期
- 🏪 **商店系统**：购买种子、解锁土地、获取加速道具
- 🎒 **仓库系统**：储存收获的农作物，一键售卖
- 🏆 **排行榜**：记录你的最高分，与好友比拼
- 🏅 **成就系统**：解锁各种有趣的成就
- 🎨 **主题切换**：绿野田园 / 秋日田园双主题
- 💾 **数据持久化**：所有进度自动保存到本地
- 📱 **移动端适配**：完美支持手机触屏操作

## 🕹️ 玩法说明

1. **选择地块**：点击空地选择要种植的土地
2. **播种**：点击下方播种按钮选择种子
3. **等待成熟**：作物会经历幼苗、成长、成熟三个阶段
4. **收割**：成熟后点击收割获得农作物
5. **售卖**：在仓库售卖农作物获得金币
6. **扩展**：用金币解锁更多土地、购买更好的种子

## 📊 难度模式

- **普通模式**：标准生长速度
- **高产速熟**：生长时间减半，种子价格提高50%

## 🏅 成就系统

| 成就 | 解锁条件 |
|------|----------|
| 🔓 首次开荒 | 解锁第一块新土地 |
| 🌾 满载丰收 | 单次收割满仓（6个以上作物） |
| ⚡ 种植速手 | 短时间内连续播种5次 |
